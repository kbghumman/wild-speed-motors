# Wild Speed Motors

Custom dealership website for Wild Speed Motors.

## Stack

- Next.js
- TypeScript
- Tailwind CSS
- Lucide icons

## Run locally

```bash
npm install
npm run dev
```

Then open `http://localhost:3000`.

## Current functionality

- Premium responsive homepage
- Vehicle search UI
- Used car inventory page
- Reusable vehicle cards
- Dynamic vehicle detail pages
- Finance / sell-your-car / showroom calls to action
- Demo inventory data
